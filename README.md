## 🌍 Overview

Travel planning today is fragmented across multiple websites. Travelers often spend hours researching destinations, comparing attractions, building itineraries, finding experiences, and contacting travel providers.

**YatraVerse** brings all of these elements together into one intelligent platform.

It combines:

* 🧠 AI-Powered Travel Planning
* 🏛️ Destination Discovery
* ✈️ Luxury Travel Experiences
* 📍 Personalized Recommendations
* 📩 Travel Concierge & Inquiry System

into a single seamless experience.

The platform is designed to help travelers explore destinations, generate itineraries, discover experiences, and plan unforgettable journeys.

---

# 🎯 Problem Statement

Modern travel planning is often fragmented, time-consuming, and overwhelming.

Travelers typically need to switch between multiple platforms to:

* Research destinations
* Build travel itineraries
* Compare experiences
* Find local attractions
* Discover cultural highlights
* Plan budgets
* Contact travel providers

This fragmented process creates several challenges:

❌ Information scattered across multiple websites

❌ No personalized itinerary planning

❌ Difficulty discovering unique local experiences

❌ Time-consuming trip research

❌ Lack of AI-assisted travel recommendations

❌ Generic travel platforms that fail to match traveler preferences

❌ Poor user experience and outdated interfaces

As a result, travelers spend more time planning and less time enjoying their journey.

---

# 💡 Solution

YatraVerse is an AI-powered luxury travel platform that simplifies the entire travel planning journey.

The platform allows users to:

✅ Explore destinations through immersive experiences

✅ Generate personalized itineraries

✅ Discover curated travel experiences

✅ Learn about attractions, culture, food, and history

✅ Connect with travel experts through inquiry forms

✅ Plan trips using AI-assisted recommendations

By combining destination discovery, AI-powered planning, and luxury travel experiences into a single platform, YatraVerse creates a smarter and more enjoyable travel planning experience.

# ⚙️ Installation & Setup

## Clone Repository

```bash
git clone <repository-url>
cd yatraverse
```

## Install Dependencies

```bash
npm install
```

## Run Development Server

```bash
npm run dev
```

Visit:

```bash
http://localhost:3000
```

```bash
npm run build
npm start
```
